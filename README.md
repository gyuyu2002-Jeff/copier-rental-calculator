# 台銀影印機租賃印量計算系統

依據臺灣銀行採購部共同供應契約設計，支援「全新影印機」與「二手影印機」獨立計費模式（分流切換、不混用）。

## 📋 兩大契約架構說明

### 🌟 全新影印機租賃（LP5-114034）
- **誤印扣除**：抄表張數自動扣除 **1.5% 誤印率**。
- **階梯累進超印計費**：
  - 超印 50% 以內：超印張數按原單價 **85%** 計收。
  - 超印 50% 以上：超出部分按原單價 **75%** 計收。
- **彩色機黑白加收費率**：
  - 第 1 組雷射彩色機：加收 **$0.40** 或 **$0.38** / 張。
  - 第 3 組噴墨彩色機：加收 **$0.30** 或 **$0.285** / 張。

### ♻️ 二手影印機租賃（LP5-114035）
- **誤印扣除**：抄表張數自動扣除 **1.5% 誤印率**。
- **固定超印計費 (無階梯)**：
  - 超出基本張數部分一律按原單價 **90% (0.9)** 計收。
- **彩色機黑白加收費率**：
  - 第 2 組雷射彩色機：加收 **$0.253 / 張**。
  - 第 3 組噴墨彩色機：加收 **$0.202 / 張**。

---

## 🚀 使用方式

1. 點擊頂部頁籤切換 **「全新影印機 (LP5-114034)」** 或 **「二手影印機 (LP5-114035)」**。
2. 選擇「契約項次規格選單」，系統自動帶入對應每月基本張數、單價與黑白加收費率。
3. 填入抄表張數（與彩色機黑白抄表張數），即時完成全機關匯總計算。
4. 點擊「🖨️ 列印 / 匯出 PDF 報表」即可匯出乾淨報表。
