# 台銀影印機租賃印量計算系統

依據臺灣銀行採購部共同供應契約設計，支援「全新影印機」與「二手影印機」獨立計費模式（分流切換、不混用）。

## 📋 兩大契約架構說明

### 🌟 全新影印機租賃（LP5-114034）
- **誤印扣除**：抄表張數自動扣除 **1.5% 誤印率**。
- **階梯累進超印計費**：
  - 超印 50% 以內：超印張數按原單價 **85%** 計收。
  - 超印 50% 以上：超出部分按原單價 **75%** 計收。
- **彩色機黑白加收費率**：
  - 第 1 組雷射彩色機：加收 **$0.40** 或 **$0.38** / 張。
  - 第 3 組噴墨彩色機：加收 **$0.30** 或 **$0.285** / 張。

### ♻️ 二手影印機租賃（LP5-114035）
- **誤印扣除**：抄表張數自動扣除 **1.5% 誤印率**。
- **固定超印計費 (無階梯)**：
  - 超出基本張數之超印部分一律按原單價 **90% (0.9)** 計收。
- **彩色機黑白加收費率**：
  - 第 2 組雷射彩色機：加收 **$0.253 / 張**。
  - 第 3 組噴墨彩色機：加收 **$0.202 / 張**。

## ⚡ 強大功能特色

1. **🎁 黑白未達標基本費金額折抵（方式 B 規範）**：
   - 當機關黑白機實際印量未達每月基本張數時，其已繳付基本費之剩餘額度價值（`未印張數 × 契約單價`），系統會自動等值折抵彩色機之超印租費或黑白加收費用，確保機關繳付之基本費發揮最大效益。

2. **⚙️ 計費模式切換**：
   - 🔗 **多台合併累加（共用總額度）模式**：自動統籌相同項次規格設備之總基本張數與總印量，完整支援台銀多台額度打通共用計費。
   - 🖨️ **單機獨立計費模式**：各台設備獨立計算基本張數與超印階梯，適合科室獨立核銷。
3. **📑 批量與快速新增設備**：
   - **批量新增**：可一鍵選擇項次並指定台數（例如一次新增 5 台），減少重複設定。
   - **快速複製**：每台設備卡片右上角設有「📋 複製此台」按鈕，快速建立相同規格。
4. **🎯 真實牌價即時連動**：選擇項次自動帶入契約原單價、基本張數與黑白加收費率。
5. **📱 手機與平版支援**：數字鍵盤自適應、小數點三位精準支援，流暢不跳格。
