# 影印機租賃印量計算系統（全新機 / 二手機・多台合併）

支援臺灣銀行共同供應契約 **LP5-114034 (全新機)** 與 **LP5-114035 (二手機)**・自動1.5%誤印率與超印累進計費。

## 📋 功能特色

- **全新機 / 二手機 雙契約架構支援**：
  - 🌟 **全新影印機 (LP5-114034)**：
    - 抄表自動扣除 1.5% 誤印率。
    - **階梯累進超額計費**：超額 50% 以內按原單價 **85%**，超額 50% 以上按原單價 **75%**。
    - 彩色機黑白加收費率：雷射加收 **$0.40 / $0.38**，噴墨加收 **$0.30 / $0.285**。
  - ♻️ **二手影印機 (LP5-114035)**：
    - 抄表自動扣除 1.5% 誤印率。
    - **固定超額計費 (無階梯)**：超出基本張數部分一律按原單價 **90%** 計收。
    - 彩色機黑白加收費率：雷射加收 **$0.253 / 張**，噴墨加收 **$0.202 / 張**。
- **項次智慧選單**：選擇項次後自動帶入該案號之基本計費張數、單價與黑白費率。
- **多台設備混合管理**：可同時新增全新機與二手機進行全機關一鍵合併試算。
- **手機體驗優化**：支援小數點專用鍵盤，打字計算即時更新不跳動。
- **列印最佳化**：內建列印專用樣式（CSS Print Media），點擊列印即可匯出乾淨報表或 PDF。

## 🚀 使用方式

直接以瀏覽器開啟 `index.html` 即可使用，不需安裝任何額外套件或後端伺服器。
