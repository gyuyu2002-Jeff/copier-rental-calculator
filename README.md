# 影印機租賃費用 - 多台合併計算系統

本系統依據共同供應契約條款設計，提供影印機租賃費用的即時試算、階梯累進超額計算、黑白加收費率計算與多台合併匯總管理。

## 📋 功能特色

- **多台設備管理**：支援動態新增、命名與刪除影印機設備。
- **誤印自動扣除**：自動依據抄表張數扣除 1.5% 誤印張數（四捨五入）。
- **階梯累進超額計費**：
  - 超額 50% 以內：超額張數按原單價 **85%** 計收。
  - 超額 50% 以上：超出部分按原單價 **75%** 計收。
- **彩色機加收黑白**：
  - 契約項次 17, 19, 20, 23, 25 項：加收 **$0.40 / 張**。
  - 契約項次 18, 21, 22, 24, 26 項：加收 **$0.38 / 張**。
- **全機關即時匯總**：頂部儀表板即時統計設備總數、總基本租費、總超額租費、總黑白加收費與應付總金額合計。
- **列印最佳化**：內建列印專用樣式（CSS Print Media），隱藏操作按鈕與邊框，方便直接列印或另存為 PDF 報表。

## 🚀 使用方式

直接以瀏覽器開啟 `index.html` 即可使用，不需安裝任何額外套件或後端伺服器。
